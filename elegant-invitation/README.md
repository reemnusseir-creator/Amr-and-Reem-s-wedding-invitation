# 💚 Amr & Reem - Elegant Wedding Invitation

A beautiful, interactive digital wedding invitation featuring a sophisticated design with an elegant dark green and gold color palette.

## 🎀 Design Features

### Visual Theme
- **Color Palette**: Deep forest green, cream, muted pink, and gold accents
- **Style**: Timeless, elegant, and romantic
- **Atmosphere**: Sophisticated digital envelope experience

### Interactive Elements
- **Page 1**: Digital envelope with animated wax seal (tap to open)
- **Page 2**: Welcome message and introduction
- **Pages 3-5**: Our Story timeline in three chapters
- **Page 6**: Event details with Google Maps integration
- **Page 7**: Interactive wishes box (guests can leave messages)
- **Page 8**: Closing message and celebration

## 📱 Navigation Features

- **Arrow Buttons**: Use Next/Back buttons to navigate
- **Keyboard**: Use arrow keys (← →) to navigate
- **Touch/Swipe**: Swipe left/right on mobile devices
- **Mouse Wheel**: Scroll to navigate
- **Click Envelope**: Click the wax seal envelope to open

## 🎯 Key Features

✅ **Responsive Design**: Works on desktop, tablet, and mobile
✅ **Smooth Animations**: Elegant transitions between pages
✅ **Interactive Wishes**: Guests can leave messages (stored in browser)
✅ **Google Maps Integration**: Easy access to venue location
✅ **Page Indicators**: Current position in the invitation
✅ **Accessibility**: Keyboard and touch navigation
✅ **LocalStorage**: Wishes persist between sessions

## 📋 Page Structure

1. **Opening**: Animated envelope with wax seal
2. **Welcome**: Invitation introduction
3. **Chapter 1**: The Beginning story
4. **Chapter 2**: Building Together
5. **Chapter 3**: The Promise
6. **Event Details**: Date, time, and location
7. **Wishes Box**: Guest messages
8. **Closing**: Final message

## 🎁 Guest Experience

- Elegant, immersive journey through the invitation
- Multiple navigation methods for different preferences
- Ability to leave personalized wishes
- Clear event information with venue map
- Beautiful animations and transitions

## 💾 Data Storage

Wishes are stored locally in the browser using LocalStorage:
- No data sent to external servers
- Persists between sessions
- Can be cleared by browser cache
