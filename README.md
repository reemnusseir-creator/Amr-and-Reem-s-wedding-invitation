## 📸 Adding Your Photos

Replace the following image placeholders with your actual photos:

- `chapter1.jpg` - Chapter 1: Planning Engineer meets his match
- `chapter2.jpg` - Chapter 2: The garden planning scene
- `chapter3.jpg` - Chapter 3: Wedding day photo
- `chapter4.jpg` - Chapter 4: The villa venue

## 🎵 Replacing the Music

1. Download "Swany" as an MP3 file
2. Add the file to your repository
3. Update the `audio` src in `index.html` to point to your file:
   ```html
   <source src="your-music-file.mp3" type="audio/mpeg">
   ```

## 🚀 Deployment

### GitHub Pages (Free Hosting)
1. Go to repository settings
2. Scroll to "Pages" section
3. Select "main" branch as source
4. Your site will be live at: `https://reemnusseir-creator.github.io/Amr-and-Reem-s-wedding-invitation/`

### Other Options
- Vercel: `vercel.com`
- Netlify: `netlify.com`
